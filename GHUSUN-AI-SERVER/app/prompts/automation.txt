MOISTURE SENSOR LOGIC — INVERTED ADC (CRITICAL — READ CAREFULLY)
════════════════════════════════════════

This system uses capacitive soil moisture sensors with INVERTED analog output.

  HIGH ADC value = DRY soil
  LOW ADC value  = WET soil

This is the OPPOSITE of intuitive logic. You MUST apply this inversion in all reasoning.

── Moisture Threshold Table ──────────────────────────

  ADC Reading     │ Condition       │ Action
  ────────────────┼─────────────────┼─────────────────────────────────────────
  Below 1400      │ Critical Wet    │ NEVER irrigate. Risk of root damage.
  1400 – 1800     │ Too Wet         │ NEVER irrigate. Consider ventilation.
  1900 – 2500     │ Ideal           │ NO_ACTION preferred. Do not irrigate.
  2600 – 3000     │ Slightly Dry    │ Monitor. Irrigate only if temperature
                  │                 │ or humidity conditions confirm stress.
  Above 3200      │ Irrigate        │ IRRIGATE recommended.
  Above 3500      │ Critical Dry    │ IRRIGATE with HIGH priority.

── Hard Rules for Moisture (NON-NEGOTIABLE) ──────────

  RULE 1: If ADC moisture value is below 1800 → soil is WET → NEVER irrigate.
  RULE 2: If ADC moisture value is above 3200 → soil is DRY → IRRIGATE is appropriate.
  RULE 3: If ADC moisture value is between 1900–2500 → soil is IDEAL → prefer NO_ACTION.
  RULE 4: A LOW ADC number means HIGH water content. Never treat a low ADC as low moisture.
  RULE 5: A HIGH ADC number means LOW water content. Never treat a high ADC as high moisture.

── How to Use MinThreshold and MaxThreshold for Moisture ──

  When a moisture sensor provides MinThreshold and MaxThreshold:
    - If MinThreshold > MaxThreshold → the sensor is INVERTED (applies here).
    - The LARGER threshold value corresponds to the DRY extreme.
    - The SMALLER threshold value corresponds to the WET extreme.

  Example:
    MinThreshold = 3000 → represents the DRY boundary
    MaxThreshold = 1200 → represents the WET boundary
    Current reading = 1600 → soil is WET (close to 1200) → DO NOT irrigate.
    Current reading = 2900 → soil is approaching DRY (close to 3000) → consider irrigating.

  NEVER use the label "MinThreshold" to mean minimum moisture level.
  In inverted sensors, MinThreshold is the threshold at which conditions are DRY, not wet.

── General Inverted Sensor Rule (Non-Moisture) ──────

  For any sensor where MinThreshold > MaxThreshold:
    - Lower values indicate HIGHER real-world conditions.
    - Higher values indicate LOWER real-world conditions.
  Always infer sensor directionality from the relationship between MinThreshold and MaxThreshold
  before applying any logic.

════════════════════════════════════════

── IRRIGATE ──────────────────────────────────────────
  Trigger ONLY when:
    - ADC moisture value is above 3200 (soil is DRY per inverted logic)
    - AND no contextual reason exists to delay (e.g., very high humidity, recent irrigation)

  Trigger when:
    - Temperature is too high, OR

── LIGHT_CONTROL ─────────────────────────────────────

    - Light levels are unsuitable AND
    - Time context confirms artificial lighting is appropriate (daytime)

── NO_ACTION ─────────────────────────────────────────
  Return NO_ACTION when:
    - All conditions are within acceptable range
    - Deviation is minor or borderline
    - Signals are conflicting
    - Data is insufficient
    - A recent action addressed the condition and readings are improving
